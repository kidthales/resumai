# DevOps & Site Reliability Engineer (Sample)

## Profile Overview

An infrastructure and reliability specialist dedicated to building resilient cloud infrastructure, automating CI/CD delivery pipelines, and maintaining high availability across production environments. Champions Infrastructure as Code (IaC), GitOps, observability, and chaos engineering practices.

## Core Technical Competencies

- **Cloud & Containerization:** AWS, GCP, Azure, Docker, Kubernetes (EKS/GKE), Helm, Containerd
- **Infrastructure as Code (IaC):** Terraform, OpenTofu, Ansible, Pulumi, CloudFormation
- **CI/CD & GitOps:** GitHub Actions, GitLab CI, ArgoCD, Flux, Jenkins
- **Observability & SRE:** Prometheus, Grafana, OpenTelemetry, Datadog, ELK Stack, SLO/SLA/SLI definition, incident response
- **Security & Compliance:** HashiCorp Vault, IAM policies, secret management, vulnerability scanning (Trivy, Snyk)

## Strategic & Operational Impact

- Automates multi-region deployment pipelines, reducing deployment lead time and eliminating manual operational errors.
- Establishes error budgets, automated alerting thresholds, and blameless post-mortem protocols to uphold 99.99% uptime SLAs.
- Optimizes cloud infrastructure spending through right-sizing, autoscaling policies, and spot instance integration.

## Target Roles & Alignment

- Site Reliability Engineer (SRE) / DevOps Engineer / Cloud Infrastructure Engineer / Platform Engineer
- High-availability cloud platforms, mission-critical infrastructure, developer platform engineering
