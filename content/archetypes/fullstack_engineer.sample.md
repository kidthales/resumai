# Full-Stack Engineer (Sample)

## Profile Overview

A versatile software engineer with end-to-end expertise spanning responsive frontend user interfaces, robust backend APIs, relational and non-relational database design, and end-to-end feature delivery. Excels at shipping complete features with high product velocity and user-centric design.

## Core Technical Competencies

- **Frontend Development:** TypeScript, JavaScript, React, Vue.js, Next.js, HTML5/CSS3, Tailwind CSS, Webpack/Vite
- **Backend Development:** PHP 8+, Node.js, Python, Symfony, Express, RESTful APIs, GraphQL
- **Databases & Caching:** PostgreSQL, MySQL, Redis, MongoDB, Prisma, Doctrine ORM
- **Testing & Tooling:** PHPUnit, Jest, Vitest, Cypress, Playwright, Docker, Git

## Strategic & Product Impact

- Bridges design mockups and backend data architectures to deliver seamless, performant end-user experiences.
- Rapidly iterates on prototypes, MVP product launches, and feature enhancements based on user feedback.
- Implements comprehensive end-to-end test suites ensuring frontend UI and backend services remain regression-free.

## Target Roles & Alignment

- Full-Stack Software Engineer / Senior Product Engineer / Web Application Developer
- Product-led growth startups, cross-functional feature teams, rapid iteration software projects
